# pi 记忆系统演进时间线

## 四个阶段

| 阶段 | 方案 | 状态 | 说明 |
|---|---|---|---|
| ① | `npm:pi-memory`（原版） | 已卸载 | 全局单例记忆；`memory_search` 需 qmd 联网下载 embedding 模型 |
| ② | `pi-memory-agent`（自研改进版） | 已卸载（2026-09-13） | 多记忆体 + 全离线检索；打包可移植到无网机器 |
| ③ | `memory-profiles`（skill） | 已删除（2026-09-13） | 为绕开「全局单例」而做的多记忆体目录管理，配合 ② 使用 |
| ④ | **`pi-memory-md`（现役）** | **使用中** | Markdown 文件 + git 版本管理的记忆库 |

## 为什么换到 ④
- ② 是**自研插件**，维护成本高；③ 是它的补丁式配套
- ④ 把记忆存成**普通 Markdown 文件**，整个文件夹就是一个 **git 仓库** → 换电脑/多设备/团队共享都能用
- 注入的是**索引**（路径 + 描述 + 标签，不含正文）而不是全文 → 很省 token，需要细节时再按需读文件

## 并存关系（重要）
`memory-profiles` 管理的 `~/.pi/agent/memory-profiles/` 与 `pi-memory-agent` 的
`~/.pi/agent/memory-agents/agents/default/` 内容**完全一致**（同为 446 / 2483 / 47 字节）——
说明 ② 首次运行把旧 profile 数据复制继承了过来。**删除 ③ 不丢信息**，这是删前核对过的。
