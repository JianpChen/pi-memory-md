# 把 pi 插件移植到无网电脑

## 核心方法
**本地路径安装不跑 `npm install`**，因此零联网：

```bash
# 目标机器上
pi install ./解压出来的目录
```

对比：`pi install npm:xxx` 会联网拉依赖；本地路径安装只读目录里的文件，
所以要求插件**自身零 npm 依赖**。

## 打包要求（踩过的经验）
- 插件必须是**纯标准库 / 零第三方依赖**，否则目标机器会因拉不到 npm 包而失败
- 整个目录可整体复制（例如 `pi-memory-agent` 只有 4 个文件：`index.ts` / `README.md` / `LICENSE` / `package.json`）
- 打包成 zip 交付，同时保留一份未打包的目录便于直接改

## ⚠️ 反例：不是所有插件都能离线装
`pi-memory-md` 就**不能**这样移植——它依赖 `nodejieba` 等 4 个 npm 包，
其中 `nodejieba` 还是**原生模块**，在 Windows 上需要预编译二进制或 Visual Studio。
详见 `global/MEMORY.md` 里的「Windows 装原生 npm 模块的通用解法」。
