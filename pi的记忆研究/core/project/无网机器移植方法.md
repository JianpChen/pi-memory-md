# 把 pi 插件移植到无网电脑

## 核心方法
**本地路径安装不跑 `npm install`**，因此零联网：

```bash
# 目标机器上
pi install ./解压出来的目录
```

对比：`pi install npm:xxx` 会联网拉依赖；本地路径安装只读目录里的文件，
所以要求插件**自身零 npm 依赖**。

## 打包要求（踩过的经验）
- 插件必须是**纯标准库 / 零第三方依赖**，否则目标机器会因拉不到 npm 包而失败
- 整个目录可整体复制（例如 `pi-memory-agent` 只有 4 个文件：`index.ts` / `README.md` / `LICENSE` / `package.json`）
- 打包成 zip 交付，同时保留一份未打包的目录便于直接改

## 有 npm 依赖的插件怎么离线装（pi-memory-md 案例）
关键事实：**`pi install <本地目录>` 不会执行 `npm install`**（源码 `dist/core/package-manager.js`
里 local 分支只校验路径存在 + 写 settings），所以只要有依赖在包内、
import 能在包内解析，就能离线跑。做法 = 把依赖闭包 **vendor 进 `node_modules/`**。

`D:/工作学习/pi的记忆研究/tools/build-offline-package.py` 一键打包：

| 依赖 | 处理 |
|---|---|
| `typebox`、`@earendil-works/pi-coding-agent` | **不打包**，pi 扩展加载器有 alias/virtualModules 内置 |
| `@orama/orama`、`gray-matter` + 7 个传递依赖 | 复制进 `node_modules/`（纯 JS） |
| `nodejieba` | 复制原生 .node + cppjieba 词典（裁掉 6.7 MB test 语料；N-API 跨 Node 版本，**不跨 OS/CPU**） |

包内附 `install-offline.cmd/.sh`、`verify-offline.mjs`（用 pi 真正的 jiti 加载器自检）、
`OFFLINE-INSTALL.md`、`THIRD-PARTY-LICENSES/`。

验证手段（可复用）：`pi -ne -e <目录> --offline --provider google --model zzz -p hi`，
再拿一个故意 `throw` 的扩展做对照组，确认「无 Failed to load extension」确实代表加载成功。

## 中文离线安装指南（文档单源）

- 指南本体：`D:/工作学习/pi的记忆研究/pi-memory-md离线安装指南.md`（11 节：安装 → 四层验证 → 记忆库配置 → 无网环境记忆库放哪 → FAQ → 升级回滚 → 包清单）
- **文档单源机制**：`tools/build-offline-package.py` 的 `load_offline_readme()` 会优先读这份指南，写成包内 `OFFLINE-INSTALL.md`；
  同时用正则把“指向包自身的 sha256”换成“见同目录 `.sha256` 文件”——否则包内容一变、包哈希也变，会自我循环。
  → 以后重新打包文档自动跟着更新，**不要手改包内 `OFFLINE-INSTALL.md`**
- 重建离线包会改变 sha256：必须同步 **`.sha256` 文件 / 指南表格 / 补丁 README+记忆** 三处

### 无网机器上记忆库怎么放（指南第 6 节，最容易踩的坑）

| 方案 | 做法 | 适用 |
|---|---|---|
| A U 盘/移动硬盘裸仓库（**推荐**） | `git init --bare E:\memory-alice.git`，`repoUrl: "E:/memory-alice.git"` | 拷着 U 盘换机器同步记忆 |
| B 局域网共享盘 | `git init --bare \\192.168.1.10\share\memory-alice.git` | 多人共用局域网，各自用不同裸仓库 = 天然隔离 |
| C 纯本地 | 只配 `localPath`，并把 `hooks` 清空 | 不换机器、不需要版本同步 |

否则 `repoUrl` 写了 GitHub 而机器无网时，会话启动会等 10 秒后报
`Unable to connect to git repository, connection timeout (10s)`。

### 验证命令实测行为（已跑过）

```
pi -ne -e "<解压目录>" --offline --no-session -nc --provider google --model zzz -p hi
→ 只报 Model "zzz" not found / No API key found
```

**没有 `Failed to load extension` 就是加载成功**；`--verbose` 不会多输出扩展加载信息。
